# patrimonio_aula05

# Descrição

O projeto Patrimônio é uma aplicação back-end desenvolvida em Node.js utilizando o framework Express. Seu objetivo é disponibilizar uma API para o gerenciamento de patrimônios, permitindo realizar operações de cadastro, consulta, atualização e exclusão de itens.

Os dados dos patrimônios são armazenados inicialmente no arquivo dados.json, que funciona como uma base de dados simples para a aplicação. Cada patrimônio possui informações como id, item, local, data de registro, valor e número de patrimônio.

## Tecnologias usadas

* Node.js
* JavaScript
* JSON
* HTML
